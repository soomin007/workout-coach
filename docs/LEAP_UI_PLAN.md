# Leap 방식 화면 개편 계획 (초안 · 2026-10-04)

레퍼런스: Leap Fitness '헬스장 루틴' 앱. 근거 정리는 `docs/research/leap_app_reference.md`.
사용자가 준 캡처 20장은 `docs/research/leap_screens/`(로컬 전용, git 제외: 다른 회사 앱 화면이고 저장소가 공개라서).
원칙: 화면 구성과 흐름은 그 앱을 따른다. 처방 · 부위 추천 · 순서 · 그립 로직(`app/js/core/`)은 그대로 둔다.
그 앱의 일러스트 · 사진 · 아이콘 파일은 쓰지 않는다. 기존 기능 삭제는 사용자 승인 후에만 한다(CLAUDE.md).

## 1. 디자인 언어 (캡처에서 읽은 것)
- 밝은 회색 바탕 위 흰 카드, 큰 둥근 모서리(약 20~24px), 그림자 거의 없음.
- 주 색 하나(진한 파랑)로 버튼 · 선택 · 진행 표시. 완료 세트는 초록 줄 전체.
- 굵은 검정 제목, 숫자는 크고 굵게(타이머 · 무게 · 횟수).
- 화면 아래에 큰 주 버튼 하나(시작 · 다음 세트 기록 · 저장 · 운동 N개 추가).
- 선택지는 큰 카드(아이콘 + 글 + 선택 시 굵은 테두리와 체크) 또는 알약 모양 칩.
- 근육 지도: 앞 · 뒤 인체 실루엣에 주동근 진한 파랑, 보조근 연한 파랑, 나머지 회색.

## 2. 화면 대응표
| Leap 화면 | 우리 앱 지금 | 계획 |
|---|---|---|
| 하단 탭 5개(훈련 · 커스텀 · 운동 · 리포트 · 내 설정), 아이콘 + 글 | 탭 3개(오늘 · 기록 · 설정) | 4개 제안: 오늘 · 운동 · 리포트 · 설정. 커스텀(루틴 직접 만들기)은 결정 필요 |
| 계획 탭: 목표 배너 + 1일 · 2일 … 잠긴 날 | 오늘 추천 카드(부위 · 이유) | 고정 30일 프로그램은 우리 방식(매일 기록 보고 추천)과 맞지 않음. "오늘 카드 + 시작" 모양만 따름. 아래에 이번 주 흐름(한 날 · 할 날) 표시 |
| 루틴 상세: 근육 지도 원, 장비 · 1RM, 운동 N개 목록(썸네일 · 세트 × 회), 시작 · 재생성 · 수정 | 시작 전 확인 시트 → 바로 세션 | 시작 전 미리보기 화면 추가: 오늘 운동 목록과 처방, 근육 지도, 시작 / 다시 추천(재생성) / 수정 |
| 운동 중: 상단 제목 + 큰 타이머(연필로 시작 · 종료 시각 수정), 종료 버튼 | 상단 카드 + 타이머 + 일시정지 | 같은 배치. 시각 수정 시트 추가(우리는 이미 활동 시각으로 계산하므로 수동 수정만) |
| 운동 카드: 썸네일(?) · 이름 · 장비 · "0/3 완료" · ⋮, 접기 | 카드 + 처방 문구 + 그립 칩 + 설명 펼침 | 카드 머리를 같은 모양으로. 처방 문구는 한 줄로 줄이고 자세한 이유는 펼침 |
| 세트 줄: 왼쪽 동그라미 체크 · 번호 · 무게 칸 · KG · 횟수(또는 00:40) 칸, 완료 시 초록 줄, 현재 세트에 화살표, 밀어서 삭제, + 세트 추가 | 번호 · 무게 · 횟수 · 오른쪽 ✓ | 같은 모양으로. 단 회색 숫자 문제(크리틱): 처방값은 진하게, 지난 기록은 작게 따로 |
| 하단 고정: "모두" + "다음 세트 기록" | 계획대로 완료 버튼(카드 안) · 휴식 바 | "다음 세트 기록" 고정 버튼을 따름. "모두"는 되돌릴 수 없어서 크리틱에서 문제로 꼽힘: 확인 또는 되돌리기를 붙여서만 |
| 숫자 키패드 + 최근 사용 칩(90kg × 2회) + 큰 다음 | 숫자 시트 + 최근 무게 칩 | 시트 대신 화면 아래 키패드로. 칩은 무게 × 횟수 묶음으로 |
| ⋮ 메뉴: 메모 · 교체 · 휴식 타이머 · 운동 제거 · 세트 줄이기 · 슈퍼셋 | ⋯ 메뉴(교체 · 사용 불가 · 이동 · 메모 · 기본값 · 삭제) | 항목은 우리 것 유지, 모양만. 삭제는 빨간색으로 구분 |
| 휴식 타이머 설정(전체 + 운동별) | 운동별 기본 휴식(설정) + 오늘만 조정 | 이미 있음. 휴식 팝업은 다음 세트 미리보기 · ±조절 · 건너뛰기 모양으로 |
| 일시 중지 화면(다시 시작 두 개) | 없음 | 따라 하지 않음. 우리 일시정지는 타이머만 |
| 운동 추가 시트: 검색 · 필터(모두 510) · 최근 · 썸네일 목록 · 다중 선택 · 선택 썸네일 줄 · "운동 3개 추가" | 선택 시트 하나씩 | 같은 흐름으로. 다중 선택 동그라미는 체크박스 관습(네모)으로 |
| 운동 상세(설명 · 기록 탭): 동작 그림, 메모, 집중 영역, 장비, 준비 · 실행 단계 | 카드 안 "운동 방법" 펼침 | 운동 탭과 카드 썸네일에서 여는 상세 시트. 설명 탭(그림 · 근육 지도 · 방법 · 주의 · 그립), 기록 탭(지난 세트 · 추이). 평상시에도 열림 |
| 운동 탭: 510개 라이브러리 · 필터 · 검색 · 최근 | 없음 | 우리 카탈로그(약 45개 + 사용자 운동)로 같은 화면 |
| 리포트 탭 | 기록 탭(세션 목록 · 수정) | 기록 목록 + 주간 볼륨 · 운동별 추이 그래프 |
| 설정: 집중 영역(근육 지도) · 목표 · 난이도 · 1RM | 컨디션 · 장비 · PT 요일 등 | 결정 필요(4절) |

## 3. 그림 자료
- 근육 지도: 앞 · 뒤 실루엣을 직접 SVG 로 그린다(영역별 path, 색은 테마 토큰). 운동 썸네일 · 상세 · 부위 칩에 같이 쓴다.
- 동작 그림: 후보 free-exercise-db(873개 운동 · JSON · 사진, Unlicense 표기). 사진 출처가 원래 다른 사이트라는 말이 있어
  쓰기 전에 출처를 확인한다. 안 되면 근육 지도 + 글로 시작하고 나중에 보강.

## 4. 사용자 결정 (2026-10-04)
1. 테마: 밝은 테마가 기본. 다크는 폰 설정이 다크일 때.
2. 탭: 4개(오늘 · 운동 · 리포트 · 설정). 커스텀 루틴 탭은 만들지 않는다. 자동 추천 + 시작 전 수정 · 추가로 대신한다.
3. 목표만 받는다(근력 · 근육량 · 근지구력 → 반복 범위). 1RM · 난이도 입력은 만들지 않는다. 무게는 기록으로 처방.
4. 동작 그림: 1순위 RepDB(github.com/sergei-argutin/exercise-dataset, 609개, 시작 · 끝 두 자세 플랫 일러스트 512px WebP).
   앱 안 사용 무료, 조건은 "Exercise data by RepDB (repdb.co)" 표기 · 데이터셋으로 재배포 금지 · AI 학습 금지.
   우리 카탈로그 운동만 골라 앱에 넣는다. 그림이 우리 운동과 맞는지 실제로 보고 확정. free-exercise-db 는 사진 출처가 불분명해 제외.

## 5. 진행 상태 (2026-10-04)
완료(배포):
- 밝은 테마 기본 · 하단 탭 4개 · 근육 지도 SVG · 운동 탭(검색 · 부위 칩) · 운동 상세(설명 · 기록 탭).
- 운동 중 화면: 왼쪽 체크 · 완료 줄 초록 · 현재 세트 화살표 · 카드 썸네일과 n/m 완료 · 하단 고정 "다음 세트 기록"(휴식 줄 포함).
- 화면 키패드 + 무게 × 횟수 최근 칩.
- 동작 그림(RepDB) 49종 + 그립 변형, 출처는 설정 탭.
- 시작 전 미리보기(근육 지도 · 목록 · 다시 추천 · 시작), 운동 추가 다중 선택 시트.
- 목표 선택(설정), 리포트(기록 탭 위: 이번 주 · 8주 막대 · 운동별 추이 · 근육별 세트).
- 코어 세션 개편(정책 8절).

하지 않은 것 · 다음 후보:
- "모두"(운동 전 세트 한 번에 완료): 크리틱에서 되돌릴 수 없어 문제였다. 우리는 카드의 "계획대로 완료"(되돌리기 가능)로 대신한다.
- 세트 줄 밀어서 삭제, 시작 · 종료 시각 직접 수정 시트.
- 탭 이름 "기록"을 Leap 처럼 "리포트"로 바꿀지(지금은 목록 · 수정 · 백업이 같이 있어 "기록" 유지).
