# 회귀 테스트 계획

## 테스트 계층

1. 순수 함수 단위 테스트
2. 상태 전이 테스트
3. 저장 및 마이그레이션 테스트
4. Playwright 기반 실제 브라우저 테스트
5. 모바일 뷰포트 시각·조작 점검

## P0: 반드시 통과해야 하는 시나리오

### 운동 교체

- 머신 운동을 덤벨 운동으로 변경한다.
- 새 운동의 name, id, equipment, load mode, increment, range, rest, unilateral, compound, sets, warmup이 모두 기대값인지 확인한다.
- 중량 입력 placeholder와 좌우 입력 구조가 즉시 바뀌는지 확인한다.
- 예상 시간이 갱신되는지 확인한다.
- 저장 후 새로고침해 같은 상태인지 확인한다.

### 역방향 교체

- 덤벨 편측 운동을 머신 양측 운동으로 바꾼다.
- 좌우 입력 필드가 일반 reps/RIR 필드로 바뀌는지 확인한다.
- 이전 편측 필드가 보이지 않으며 저장 데이터에도 잘못 계승되지 않는지 확인한다.

### 미완료 입력 보호

- 중량이나 반복수를 입력하고 운동 변경을 시도한다.
- 취소하면 모든 상태, custom exercise 수, preference가 정확히 이전과 같은지 확인한다.
- 승인하면 정의된 정책대로 교체되는지 확인한다.

### 일부 완료 후 교체

- 3세트 중 1세트를 완료한다.
- 운동을 변경한다.
- 완료 1세트는 기존 운동, 남은 세트는 새 운동으로 분리되는지 확인한다.
- 세션 종료 후 performance history 연결이 올바른지 확인한다.

### 세션 임시값과 영구값 분리

- 반복수 하락으로 오늘 휴식을 자동 연장한다.
- 세션을 종료하고 같은 운동의 새 세션을 만든다.
- 사용자 기본 휴식은 자동 연장 전 값인지 확인한다.
- 사용자가 직접 기본 휴식을 변경한 경우에는 다음 세션에 유지되는지 확인한다.

### 날짜

- 진행 중 세션의 실제 운동 날짜를 수정한다.
- 저장 후 history와 performance history가 모두 수정된 날짜를 사용하는지 확인한다.
- 새로고침 후에도 유지되는지 확인한다.

### 직접 운동 추가

- 새 custom exercise를 만든다.
- 카드, 세트 수, 입력 구조, 예상 시간이 즉시 갱신되는지 확인한다.
- 새로고침 후 custom exercise가 유지되는지 확인한다.

### 저장과 복원

- 입력 중 새로고침 후 세션을 복원한다.
- JSON export → 앱 상태 변경 → import 후 완전히 복원되는지 확인한다.
- malformed JSON은 기존 상태를 훼손하지 않아야 한다.
- localStorage의 오래된 revision과 IndexedDB의 최신 revision이 있을 때 최신본을 선택해야 한다.

## P1: 기존 기능 회귀

- 30/45/60/75분별 계획 생성
- Push/Pull/Lower/Core 핵심 슬롯 충족
- 장비 비활성화 시 해당 운동 자동 추천 제외
- 같은 세션 중복 운동 방지
- DOMS, 통증, 피로, PT, 일요일 휴무 규칙
- assist 모드에서 향상 시 보조중량 감소
- 일반 모드에서 향상 시 중량 증가
- 빈 RIR과 RIR 0 구분
- 세트 추가·삭제와 기록 보호
- 운동 삭제 시 휴식 타이머 정리
- 휴식 +30/-15 및 overtime 표시
- 이력 날짜 및 부위 수정
- PT mixed 입력 검증
- CSV/TXT에 편측 및 일반 기록 모두 포함

## 마이그레이션 fixture

가능하면 실제 익명화된 다음 파일을 `tests/fixtures/`에 둔다.

- v7 JSON
- v8 JSON
- v9 JSON
- 진행 중 세션이 있는 JSON
- 편측 기록이 있는 JSON
- custom exercise와 사용자 선호가 있는 JSON

각 fixture에 대해 다음을 확인한다.

- 데이터가 사라지지 않는다.
- 알 수 없는 오래된 필드는 안전하게 처리된다.
- 현재 스키마에 필요한 기본값이 채워진다.
- 다시 export/import해도 의미가 변하지 않는다.

## 모바일 점검

최소 뷰포트:

- 360 × 800
- 390 × 844
- 412 × 915

확인 항목:

- 일반 세트 행 입력 가능
- 편측 8열 입력의 가독성과 터치 가능성
- 하단 고정 버튼이 내용을 가리지 않음
- 모달 스크롤 및 닫기 가능
- 키보드가 열린 상태에서 현재 입력 필드 접근 가능
- 운동 변경 후 화면 점프나 입력 손실 없음

## 완료 증거

완료 보고에는 다음을 포함한다.

- 실행한 명령
- 통과/실패 테스트 수
- 실패한 테스트가 있다면 정확한 목록
- 변경 파일 요약
- 기존 v9 대비 의도적인 동작 변경
- 아직 수동 확인이 필요한 항목
- 최종 standalone HTML 경로와 checksum
