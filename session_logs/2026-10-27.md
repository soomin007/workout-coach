# 2026-10-27 세션 로그

## 요약
덤벨 · 이지바 팔 운동 세 가지(덤벨 오버헤드 익스텐션, 이지바 스컬 크러셔, 이지바 컬)를 카탈로그에 넣고,
직접 추가했던 '암 풀 다운'을 스트레이트 암 풀다운으로 옮겼다. 직접 추가 운동이 집 운동에 섞이던 장비 기본값도 고쳤다.

## 주요 변경
- `app/js/core/catalog.js`: 장비 ez_bar(이지바), db_oh_ext · skull_crusher(push), straight_arm_pd · ez_curl(pull),
  pull 보조 자리 lat_isolation('광배 고립')과 호환표 · 순서 · 이름표.
- `app/js/core/guide.js`: 새 운동 네 개 하는 방법. `app/js/core/media.js` + `app/img/ex/`: RepDB 그림 네 쌍(320px).
- `app/js/core/session.js` customEquipment, `app/js/core/schema.js` 옛 직접 추가 운동 장비 보정, `app/js/ui/library.js` 장비 이름표('헬스장 기구').
- `tests/unit/gym_steps.test.js` 4개. `docs/COACHING_POLICY.md` 20절, `known-issues.md` 32.

## 결정 사항
- 이지바는 원판식, 빈 바 10kg(사용자 확인)이라 총중량 · 5kg 단위 · start 10.
- 새 삼두 · 이두 운동은 기존 운동보다 순위를 낮췄다. 평소 구성은 그대로고, 교체 후보와 강조 날 두 번째 운동으로 쓰인다.
  삼두 핵심 자리는 보조 로테이션 대상이 아니라 "번갈아 나온다"는 효과는 없다(10/26 답변에서 그렇게 말한 부분은 바로잡아 전했다).
- 스트레이트 암 풀다운을 랫풀다운 자리에 두자 로테이션 감점 때문에 60분 Pull 에서 랫풀다운이 빠졌다.
  따로 lat_isolation 자리를 두고 우선순위 60으로 낮춰 60분은 랫풀다운 유지, 75분 · 광배 강조 날에 더해지게 했다.
- 이두 강조 날에는 바이셉 컬, 이지바 컬, 해머컬 세 가지가 나온다(실기록 계획으로 확인).

## 세션 2

### 요약
그림 없는 운동을 정리하고, 헬스장에 확실히 있는 장비로 하는 운동 일곱 가지를 그림 · 하는 방법과 함께 넣었다.
세션 시작 훅이 직접 추가 운동도 알리게 했다.

### 주요 변경
- `app/js/core/catalog.js`: db_bench, db_shoulder_press(별칭 덤벨 오버헤드 프레스), incline_db_fly, incline_curl, db_squat, smith_hip_thrust, hanging_knee_raise.
- `app/js/core/media.js` + `app/img/ex/`: 새 운동 그림 일곱 쌍과 케이블 리어델트 플라이(cable-reverse-fly). 그림 없는 운동은 한발 힙 쓰러스트 하나.
- `app/js/core/guide.js`: 새 운동 일곱 개 하는 방법.
- `scripts/memos.mjs`: customExercises 를 '[직접 추가 운동]' 줄로 낸다. 장부에 암 풀 다운 키 기록.
- `tests/unit/gym_steps.test.js`: 그림 존재(파일까지) 검사, 집 운동 검사. 정책 20절, known-issues 26.

### 결정 사항
- 사용자 헬스장은 작은 PT 샵이라 전용 머신(펙덱, 딥스, 프리처, 핵 스쿼트)이 없다. 덤벨 · 벤치 · 스미스 · 케이블 · 철봉 운동만 넣었다.
- 평소 구성이 바뀌지 않게, 실기록으로 부위 · 시간 · 강조 · 집 운동 34개 계획을 추가 전후로 비교했다. 덤벨 벤치와 인클라인 덤벨 플라이가
  지난번 케이블 플라이를 로테이션으로 밀어내서 우선순위를 55로 낮추고 다시 비교해 같음을 확인했다.
- 고블릿 스쿼트는 그림이 케틀벨이라 덤벨 스쿼트로 바꿨다.
- 한발 힙 쓰러스트는 RepDB 에 바닥 브릿지 그림뿐이라 그림 없이 둔다(다른 동작 그림은 오해를 만든다).

### 미해결 / 다음 할 일
- 폰이 새 버전을 받으면 암 풀 다운 기록이 스트레이트 암 풀다운으로 옮겨지고, 훅의 [직접 추가 운동] 줄도 사라진다.
