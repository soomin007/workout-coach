운동을 마친 날에도 뜨던 "오늘 추천 · PT 날", 지난 시간·강도로 조용히 시작되던 세션,

## 결정 사항
- 필수 확인 항목은 부위 · 컨디션 · 시간 · 강도. 근육통·통증은 "없음"이 기본으로 보이는 상태로 확인 처리.
  오늘 이미 고른 값은 채워 둬서 같은 날 두 번 묻지 않는다 (입력 최소화 원칙과의 절충).
- 완료 판정은 오늘 날짜 기록(직접 세션 또는 PT) 유무. 완료 카드에서 추가 운동은 선택이며 PT 기록 버튼은 항상 둔다.
- 크리틱에서 가져온 원칙: 같은 기능은 같은 이름(메모), 숨은 기능 노출(메모 버튼), 기억 대신 인식(최근 무게 칩),
  사용자 입력 보존(오류 시 글 유지). 휴식 바(남은 시간 · 다음 세트 · ±조절 · 끝)는 이미 크리틱의 좋은 예와 같은 구조.

## 세션 2

"근력 중심" 레퍼런스 조사 후 제안서를 썼다(구현은 결정 대기). PT 요일을 확정이 아닌 "보통"으로 바꿨다.
운동 설명을 근육 정보에서 하는 방법·주의할 점으로 바꿨고, ☀ 버튼에 글자 라벨을 달았다.
동기화 저장소의 10/1 기록에 사용자가 복기한 메모 두 개를 넣고, 레그프레스 중량 방식 실수를 되돌렸다.

### 주요 변경
- `docs/research/strength_day_proposal.md`: DUP · RTS 톱세트 · Fitbod · 휴식 연구를 종합한 제안과 결정 항목 A~C.

- `app/js/ui/views.js`: 운동 설명을 "운동 방법 · 주의할 점"으로 바꾸고 기존 cue 는 "내 체크 포인트"로 표시.
  "오늘 PT 없어요" 토글, 화면 유지 버튼 글자 라벨, 설정 라벨 "PT 요일 (보통)".

- 데이터(soomin007/workout-log): 스쿼트·어브덕션 메모에 "(복기)"를 붙여 복원, prefs.legpress.loadMode(assist) 삭제, revision 503.

### 결정 사항
- PT 요일은 자동 추론(최근 PT 기록으로 이번 주 PT 생략 판단)을 하지 않고 수동 토글만 둔다. PT 빈도가 확인되지 않아서다.
- 운동 설명은 일반 코칭 큐를 짧게 옮겼다. 사용자 개인 관찰(cue)은 지우지 않고 따로 보여 준다.

## 세션 3

### 요약
근력 중심 제안을 권장안(A 톱세트+백오프 · B 3~5회 · C 수동 선택)으로 구현했다.
레그프레스는 원판식이라 한쪽당 방식으로 바꾸고, 운동별 기본값에 "기구 무게(공중량)"를 추가했다.

### 주요 변경
- `app/js/core/coach.js`: `HEAVY` 상수, `heavyEligible`, `estimate1RM`, `heavyPrescribe`, `backoffWeight`, 워밍업 'heavy' 단계,
  `lastPerformance(…, { heavy })` 로 평소·무거운 날 기록 분리, 프로필 `base`.
- `app/js/core/session.js`: `makeHeavy`(createSession · 교체에서 적용), `coachHeavy`, 톱세트 수정 시 백오프 90% 재계산,
  기록에 `heavy` · `base` 저장, setPref 에 base.
- `app/js/core/plan.js`: 근력 중심의 세트 +1 규칙 삭제.
- `app/js/core/catalog.js`: 싱글 레그프레스 mode per_side.
- `app/js/ui/views.js` · `main.js`: 톱세트 표시, 톱세트 RIR 칩, 무거운 날 안내, 공중량·총중량 표시, 기본값 시트에 기구 무게, 근력 중심 경고.
- 테스트: `tests/unit/heavy.test.js` 7개, E2E 2개, 레이아웃 1개. 정책 문서 10절.

### 결정 사항
- 톱세트와 백오프 세트의 타입은 'main' 으로 두고, 세트에 `heavy` 표시만 붙였다. 볼륨 계산은 그대로 두고 처방만 분리하려는 선택이다.
  기존 'backoff' 타입은 볼륨에서 빠지기 때문이다.
- 공중량은 총중량 표시에만 쓴다. 처방과 증량은 원판 무게로 한다.

### 미해결 / 다음 할 일
- 사용자가 레그프레스 기본값에 실제 공중량을 입력해야 총중량이 보인다.
- 실사용 후 확인할 것: 톱세트 추정 무게가 맞는지(첫 무거운 날 스쿼트 97.5kg 예상), 백오프 2세트가 적당한지.
