# 2026-10-06 세션 로그

## 요약
10/5 Push 세션 기록과 메모를 분석했다. 메모의 두 질문(종목 수 감소 · 어깨를 더 하고 싶음)을 진단하고,
사용자 결정에 따라 '오늘 강조 부위' 칩을 만들었다. 케이블 증량 단위를 5kg 로 맞췄다.

## 분석 (10/5 Push, 45분 선택 · 실제 49분)
- 앱 추천: 벤치 3 · 인클라인 2 · OHP 3 · 레터럴 3 · 푸시다운 2 (13세트, 예상 47분). 실제: 벤치 대신 푸쉬업 2세트(쉬움 · RIR 3),
  인클라인 3 · OHP 3 · 레터럴 3(+백오프) · 푸시다운 3 = 14세트. 지금까지 밀기 중 세트가 가장 많다.
- (정정) 메모의 "전에 비해"는 예전에 쓰던 기성품 앱과의 비교였다. 그 앱의 루틴 크기 데이터가 없어 아직 비교하지 못했다.
- 종목 수: 휴식 정책은 바뀌지 않았다(근육량 목표는 카탈로그 휴식 그대로). 45분이면 5종목이 상한(60분 6종목).
  실제 휴식(✓ 간격)은 처방 휴식 + 세트 수행 시간과 맞다. 사용자 결정: 그대로 둔다.
- 어깨: 근육별 부족분으로는 가슴(0/10)이 측면 어깨(OHP 간접 포함 4.5/8)보다 커서 보조 자리가 가슴으로 갔고,
  Push 보조 슬롯이 전부 가슴 운동이라 구조적으로 어깨가 늘 수 없었다.
- 가슴 메인이 푸쉬업 2세트(쉬움)로 대체되어 오늘 가슴 자극은 약했다. 원인 기록 없음(기구 대기로 추정).

## 주요 변경
- `app/js/core/catalog.js`: `EMPHASIS` · `emphasisMuscles`, 케이블 운동 증량 2.5 → 5.
- `app/js/core/plan.js`: `buildPlan` 의 `where.emphasis`(앞으로 · 세트 +1 · 나머지 핵심 2세트 · 보조 자리 우선, 같은 역할 두 번째 허용).
- `app/js/core/session.js`: `setEmphasis` 전이, `session.emphasis`, 다시 추천에서 유지.
- `app/js/ui/views.js` · `main.js` · `styles.css`: 미리보기 칩 줄.
- `docs/COACHING_POLICY.md` 15절. 단위 · E2E 테스트 각 1개.

## 결정 사항
- 자동 부족분 계산에 어깨 슬롯만 더하는 안은 버렸다: 오늘 같은 날은 여전히 가슴이 먼저 나온다. 사용자 의도는 선택으로 받는다(RP 특화 · Fitbod 타깃 근육).
- 강조하지 않은 핵심 운동도 빼지 않고 2세트(유지 볼륨). 메인 진행 추적이 끊기지 않게.

## 미해결 / 다음 할 일
- Pull 에서 이두 강조 시 컬이 풀업보다 앞에 온다. 선행 피로 처방으로 무게는 보정되지만 실사용 느낌 확인 필요.
- 메인 운동을 맨몸 운동으로 바꾼 날은 그 부위 자극이 약하다는 안내가 있으면 좋을지 검토.
