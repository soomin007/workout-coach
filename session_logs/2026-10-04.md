# 2026-10-04 세션 로그

## 요약
Leap '헬스장 루틴' 앱 크리틱 대화(공유 링크)를 정리해 레퍼런스 문서로 남기고, 10/4 Core 세션 메모를 반영했다.
코어 항회전 기본을 숄더 탭으로, 버티기 타이머, 그립 그림 재작성.

## 주요 변경
- `docs/research/leap_app_reference.md`(신규): 구조 · 기록 화면 · 따라 할 것 · 피할 것 · 차별점(무게 · 횟수 추천 부재).
- `app/js/core/catalog.js` · `plan.js` · `coach.js`: 플랭크 숄더 탭 추가(항회전 기본), 버드독 `kneeling` + 오늘 무릎 통증이면 제외.
- `app/js/core/guide.js`: 데드버그(고관절 굽힘근 대신 배 쓰기), 리버스 크런치(골반 감기), 버드독 · 숄더 탭 설명.
- `app/js/core/hold.js` · `app/js/ui/hold.js`(신규), `session.recordHold`: 시간형 운동 타이머(준비 5초 · 한쪽 · 자세 바꾸기 10초 · 반대쪽).
- `app/js/ui/gripart.js`: 손 모양 재작성, V바 회전 부호 수정, 불투명 손 색(테마 토큰 `--hand-fill`).
- `tests/e2e/*`: 시계를 평일로 고정(known-issues 15), 버티기 타이머 흐름 · 레이아웃 테스트.

## 결정 사항
- 사용자가 매트를 깔아도 버드독에서 무릎이 아팠다고 해서 매트 안내만으로 끝내지 않고 기본 종목을 바꿨다.
- 허리는 복근 앱 루틴에서 아프지 않았다는 답을 받음: 코어 재구성(굽힘 운동 핵심 슬롯화, 4~6종목)은 다음 작업.
- 버티기 타이머는 시트 + 시각 차이 계산(화면이 꺼져도 따라잡음), 중간에 멈추면 버틴 시간만 기록.

### 요약
홈의 "추가로 Core 하기" 버그를 고치고, 사용자가 준 Leap 캡처 20장으로 화면 대응표를 만들어 결정을 받은 뒤 개편 1단계를 배포했다.

### 주요 변경
- `app/js/core/plan.js`: 추가 운동 추천이 모든 경로에서 오늘 한 부위를 제외(`noRepeat`). 일요일 · 휴무일 경로가 먼저 반환하던 것이 원인.
- `docs/LEAP_UI_PLAN.md`(신규): 디자인 언어, 화면 대응표, 사용자 결정, 단계. 캡처는 `docs/research/leap_screens/`(git 제외, 저장소가 공개라서).
- `app/styles.css` · `index.html`: 밝은 테마 기본(다크는 시스템 설정), 하단 탭 4개 + 아이콘.
- `app/js/ui/bodymap.js`(신규): 앞 · 뒤 근육 지도 SVG. `app/js/ui/library.js`(신규): 운동 탭(검색 · 부위 칩), 운동 상세 시트(설명 · 기록).

### 결정 사항
- 사용자 결정: 밝은 테마 기본 · 탭 4개(커스텀 루틴 없음) · 목표만 받고 1RM · 난이도 입력 없음 · 동작 그림은 공개 자료 조사 후.
- 동작 그림 1순위 RepDB(앱 안 사용 무료, 출처 표기 · 데이터셋 재배포 금지). free-exercise-db 는 사진 출처 불분명으로 제외.
- 검색은 다시 그리지 않고 DOM 으로 거른다(입력 중 포커스 유지).
