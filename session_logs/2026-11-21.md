### 결정 사항
- 버튼은 '세트 완료' 하나이고 버티기 세트에서는 같은 자리가 '버티기 시작'이 된다(사용자 결정). 잠금 해제, 앱 열기, 다음 세트 기록을 한 번으로 줄이는 자리라
  운동 중 버튼을 늘리지 않는다는 원칙과 맞는다. 휴식 조절과 건너뛰기는 앱에만 둔다.
- 잠긴 동안 누른 기록은 네이티브 기록장에 두고, 앱이 깨어나면 누른 시각 그대로 toggleSetDone 과 recordHold 에 넣는다. 넣은 번호를 같은 커밋에서
  세션 noticeSeq 에 적어 두 번 들어가지 않게 했다. 포그라운드 서비스와 미디어 알림은 쓰지 않았다(근거는 research 문서).
- 알림이 미리 알아야 하는 단계와 문구는 웹 코드가 같은 전이 함수로 계산해 넘긴다. 문구를 고칠 때 APK 를 다시 깔 필요가 없다.
- 폰에서 보니 One UI 잠금 화면은 알림을 접어서 보여 기본 버튼이 숨었다. 라이브 업데이트를 못 쓰는 폰에서는 접힌 줄에 남은 시간과 버튼을 그리도록 더했다.
  버튼 수는 그대로다. 사용자 폰은 승격이 막혀 있어(canPostPromotedNotifications false, 나우 바는 허용 목록 앱만) 상태 바 칩과 나우 바에는 뜨지 않는다.
- 네이티브 시험은 패키지가 다른 시험용 앱으로 했다. 쓰는 앱의 기록과 GitHub 동기화에 시험 세트가 남지 않게 하려는 것이다.
  시험하며 폰에 한 일은 adb 로 화면 켜고 끄기, 알림 창 열기와 탭, 시험용 앱 프로세스 끝내기, 측정 동안의 배터리 상태 흉내와 Doze 강제(둘 다 되돌림)다.
  쓰는 앱은 덮어 설치한 뒤 플러그인 목록과 기록 수만 읽었다(기록 35개 그대로, 진행 중 세션 없음).
