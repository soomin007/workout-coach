## 결정 사항
- v9 를 풀어 쓰는 단계는 생략: 전부 읽고 결함을 코드로 확인했고, 데이터 구조와 UI 를 새로 설계하기로 했으므로 모듈로 옮기며 고쳐 씀.
- 배포본은 빌드 없는 ES 모듈. npm 은 개발 테스트 도구(Playwright)에만.
- 상태 변경은 store.commit(초안 복제 → 전이 → 교체). 예외 시 상태 불변이라 "취소 시 아무것도 안 남음"을 구조로 보장.
- 사용자 확인은 전이 전에 UI 에서 (v9 finishSession 중복 저장 버그 재발 방지).
- 입력 최소화(사용자 최대 고충): 처방 미리 채움 + ✓ 한 번, 운동당 느낌 3단계, ✓ 간격으로 휴식 자동 기록, 한 줄 입력.
- 코칭 정책은 사용자가 위임. 조사 결과를 근거로 결정했고 PT 트레이너 검토를 권함.
- 푸시 알림은 최종 단계 네이티브 앱에서 (안드로이드). 웹 알림 예약 API 는 크롬이 개발 중단.
- v7 실데이터 보정: 교체 버그로 오염된 운동 id 2건, 7분짜리 세션 시간, 영구 기구 없음 복원.
